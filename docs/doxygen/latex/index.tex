 Aplicación de gestión de tareas y calendario desarrollada con Java, Spring Boot, Vaadin, My\+SQL y Maven.

El proyecto incluye gestión de usuarios, creación y edición de tareas, categorías, calendario, tests automáticos, integración continua (CI) y generación de informes de calidad.

\doxysection*{Requisitos previos}

Antes de empezar es necesario instalar\+:

\doxysubsection*{1. Git}

Descargar\+: \href{https://git-scm.com/downloads}{\texttt{ https\+://git-\/scm.\+com/downloads}}

Instalar con configuración por defecto.

Descargar\+: \href{https://code.visualstudio.com/}{\texttt{ https\+://code.\+visualstudio.\+com/}}

\doxysubsection*{3. Java JDK 21}

Descargar\+: \href{https://adoptium.net/}{\texttt{ https\+://adoptium.\+net/}}
