This directory is automatically generated by Vaadin and contains the pre-\/compiled frontend files/resources for your project (frontend development bundle).

It should be added to Version Control System and committed, so that other developers do not have to compile it again.

Frontend development bundle is automatically updated when needed\+:
\begin{DoxyItemize}
\item an npm/pnpm package is added with @\+Npm\+Package or directly into package.\+json
\item CSS, Java\+Script or Type\+Script files are added with @\+Css\+Import, @\+Js\+Module or @\+Java\+Script
\item Vaadin add-\/on with front-\/end customizations is added
\item Custom theme imports/assets added into \textquotesingle{}theme.\+json\textquotesingle{} file
\item Exported web component is added.
\end{DoxyItemize}

If your project development needs a hot deployment of the frontend changes, you can switch Flow to use Vite development server (default in Vaadin 23.\+3 and earlier versions)\+:
\begin{DoxyItemize}
\item set {\ttfamily vaadin.\+frontend.\+hotdeploy=true} in {\ttfamily application.\+properties}
\item configure {\ttfamily vaadin-\/maven-\/plugin}\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{<configuration>}
\DoxyCodeLine{\ \ \ \ <frontendHotdeploy>true</frontendHotdeploy>}
\DoxyCodeLine{</configuration>}

\end{DoxyCode}

\item configure {\ttfamily jetty-\/maven-\/plugin}\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{<configuration>}
\DoxyCodeLine{\ \ \ \ <systemProperties>}
\DoxyCodeLine{\ \ \ \ \ \ \ \ <vaadin.frontend.hotdeploy>true</vaadin.frontend.hotdeploy>}
\DoxyCodeLine{\ \ \ \ </systemProperties>}
\DoxyCodeLine{</configuration>}

\end{DoxyCode}

\end{DoxyItemize}
